# Mål og omfang

## Formål

STOK Emballage i Norge og på Island, tidligere BEWI Food, trenger en ny nettside som erstatter bewifood.com. PoC-en skal vise hvordan den kan se ut og fungere med Next.js og Sanity. Den gir STOK et konkret grunnlag for å vurdere løsningen før et eventuelt fullt prosjekt.

## Hva PoC-en skal vise

1. **Gjenkjennelig STOK-profil.** Siden bruker samme farger, fonter og visuelle språk som stok.dk.
2. **Norsk innhold.** Bransjer, produkter og kontaktpersoner bygger på det som finnes på bewifood.com.
3. **Redaktørstyrt innhold.** Redaktører lager og endrer sider i Sanity Studio uten utvikler.
4. **Fleksible sider bygget av moduler.** Redaktøren setter sammen sider av ferdige seksjoner (hero, kort, tekst med bilde, CTA-banner osv.).
5. **Strukturert produktkatalog.** Produkter med grupper, bransjer og filtre.
6. **Forhåndsvisning.** Redaktøren ser endringer på siden før publisering.
7. **To markeder.** Norge og Island med markedsvelger og eget innhold per marked.
8. **God ytelse og SEO.** Raske sider, riktige metadata og strukturerte data.

## Foreslått omfang (til avklaring)

| Med i PoC | Utenfor PoC |
|---|---|
| Forside | Nettbutikk og handlekurv |
| 2–3 bransjesider (f.eks. fisk og sjømat, næringsmiddel, transport og lagring) | Integrasjon mot ERP eller produktdata |
| Produktkatalog med filtre og produktsider (et utvalg på 15–20 produkter) | Innlogging og kundeportal |
| Nyhetsoversikt og nyhetsartikkel | Full migrering av alle produkter og nyheter |
| Om oss, bærekraft og åpenhetsloven | Flere markeder enn Norge og Island |
| Markedsvelger og islandsk versjon av forside, kontaktside, én bransjeside og noen produkter | |
| Kontaktside med kontaktpersoner og avdelinger | Søk (kan vurderes) |
| Global meny, mega-meny og bunntekst | Nyhetsbrev-integrasjon |
| Kontaktskjema (enkel løsning) | Karriere med stillingsannonser |

## Suksesskriterier

- STOK kjenner igjen profilen sin.
- En redaktør kan lage en ny side fra moduler på under 15 minutter.
- Lighthouse-score over 90 på ytelse, tilgjengelighet og SEO.
- Løsningen kjører på en offentlig test-URL som STOK kan klikke rundt i.
