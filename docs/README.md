# STOK Norge – proof of concept

Proof of concept (PoC) på ny nettløsning for STOK Norge, tidligere BEWI Food. Løsningen skal erstatte [bewifood.com](https://bewifood.com) og gjenbruker den grafiske profilen fra den danske nettsiden [stok.dk](https://www.stok.dk).

**Status:** Planlegging. Utviklingen starter når planen er godkjent.
